Leva o que foi cobrado no balcão ao grupo ``detPag`` da NF-e: um grupo
por pagamento, com a forma (``tPag``), o valor e — nas formas que o
admitem — o grupo ``card`` com tipo de integração, código de autorização
e bandeira.

O ``l10n_br_pos`` captura os dados; este módulo só os traduz para o
leiaute. Instala-se sozinho quando os dois estão presentes.
